# Katzenspiel

Mäuse laufen über den Bildschirm, die Katze fängt sie mit der Pfote. Bei einem Treffer quiekt die Maus und flitzt davon.

Eine Web-App ohne Bibliotheken und ohne Build-Schritt. Tempo, Größe und Anzahl der Mäuse stehen in `SETTINGS` am Anfang von `game.js`.

Zum Ausprobieren `index.html` im Browser öffnen. Installation und Offline-Betrieb funktionieren nur über HTTPS, zum Beispiel mit GitHub Pages.
